# Task Manager

一个使用python编写的命令行任务管理程序

## 功能

- 添加任务
- 查看任务
- 删除任务
- 修改任务
- 完成任务
- 优先级管理
- 截止日期管理
- JSON数据持久化
- git版本控制

## 项目结构
```text
task_manager/
|- main.py
|- task.py
|- storage.py
|- task_manager.py
|_ tasks.json
```

## 技术

- python 
- Object Oriented Programming
- File I/O
- JSON
- Git

## 如何运行

确保电脑已经安装了python,然后运行:
```bash
python main.py
```
